# 前置知识

## 方向导数
- 标量沿着某一方向的变化速度
    - $$\text{方向导数} = \text{梯度}\cdot\cos(\text{方向与梯度的夹角})$$
- 方向导数最大为 |g|，沿梯度方向
    - 向其他角度变化时，该方向的方向导数 = $$|g|\cos(g, e)$$（g 为梯度矢量，e 为方向单位向量）
- 梯度与等值面垂直
---
## 哈密顿算子
- 方向导数的运算里把公共的`方向u`提出来，微分的一个运算符（即 nabla 算子 ∇）
---
## 矢量场的通量和散度
1. 通量
    - 场线在规定区域的面内的有效积分
    - 如果曲面闭合成体，则入通量和出通量抵消
        - 有源，则根据通量结果判断源的类型：+/=/0
    - 例如：磁通量
        - 磁通 $$\Phi = B\cdot S\cdot\sin\alpha$$
2. 散度
    - 通量在闭合曲面内，闭合区域内每一个体积点所具有的通量叫作散度
        - 散度 = 通量/体积
        - 说白了，就是每一点的通量
        - 看看这个点是矢量的+/-/0源，把原本的全局情况转换为的每一点
    - 散度处处为0：该场为无源场
---
## 环量与旋度
1. 环量
    - 矢量在闭合线上的积分，判断是否有功，是否有漩涡存在
2. 旋度
    - 在闭合线上的每一点的环量
        - 旋度 = 环量/面积
    - 是描述旋转程度的量，判断有无漩涡
---
## 两个恒等式
1. 标量的梯度的旋度 = 0
    - $$\nabla \times (\nabla\varphi) = 0$$
2. 矢量的旋度的散度 = 0
    - $$\nabla \cdot (\nabla \times A) = 0$$
---
## 公式汇总
| 公式 | 名称/含义 |
|------|-----------|
| $$\nabla = \frac{\partial}{\partial x}\hat{x} + \frac{\partial}{\partial y}\hat{y} + \frac{\partial}{\partial z}\hat{z}$$ | 哈密顿算子（nabla），方向导数的公共微分运算符 |
| $$\text{方向导数} = |g|\cos(g,e)$$ | 标量沿方向 e 的变化率，沿梯度方向最大，等于 \|g\| |
| $$\Phi = B\cdot S\cdot\sin\alpha$$ | 磁通量：磁感应强度在面 S 上的有效积分 |
| $$\text{散度} = \frac{\text{通量}}{\text{体积}}$$ | 收敛区域内每一点的通量，判断点源 +/=/0 |
| $$\text{旋度} = \frac{\text{环量}}{\text{面积}}$$ | 闭合线上每一点的环量，判断有无漩涡 |
| $$\nabla\times(\nabla\varphi) = 0$$ | 恒等式一：标量梯度的旋度恒为 0 |
| $$\nabla\cdot(\nabla\times A) = 0$$ | 恒等式二：矢量旋度的散度恒为 0 |
