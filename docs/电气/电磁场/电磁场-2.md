## 1-2
### 欧姆定律与焦耳定律
1. 欧姆定律的微分形式
    - U = IR
        - R = l/S*α（α为电导率）
        - I = 电流密度*v
            - J = α*E
2. 焦耳定律的微分形式
    - W = FL
        - F = qE = eE
        - W = FL = eE*vt*N
            - N表示电荷量
            - 电流密度 = N*e
            - J = 电流密度*v
            - 所以：e*N*v = J
            - 所以：W = J*E*t
        - 能量密度 = J*E

1. 电源能量
    - 电源：将电能转换为其他能量
    - 外力：将其他能量转换为电能
    - 外力场强：外力/q
    - 电源动势：外力*l

### 电流连续性方程
1. 电荷守恒
    - 单位时间，区域流出电荷量 = 区域内的减少量
    - J*S = 0
    - Laplace · J = 0
2. 恒定电场的基本方程
    - J*S = 0
        - 微分形式  ->  Laplace·J = 0
    - E*L = 0
        - 微分形式  ->  Laplace*E = 0
    - 两种情况
        - 路径含有电源：(E+Ee)*l
        - 路径不含电源：(E)*l
        > 电源电压Ee
3. 分界面的衔接条件
    - E1t = E2t
    - J1n = J2n
    - tan(α1)/tan(α2) = α1/α2
    > 导体内，E,J只有切线方向，没有法向方向
    > 由良导体到不良导体，电流方向由切向经过折射几乎变为法向方向，电导率差别过大，10的8次方
4. 边值问题
    - 和静电场的三种情况一样
5. 镜像法
    - 把静电场的q换成I就行，其他的完全一样
