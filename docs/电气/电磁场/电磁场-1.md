# 第一章：静电场
## 1-1
### 场强
1. 电场强度
    - F = q*E
    - E = q/4ΠR²
2. 叠加积分 -> 电场强度
    - 点：同1
    - 线：公式
    - 面：类型
    - 体：类型
### 电位
3. 电位
    - 电势高度
    - 电势 = q/4ΠR
    - 电场力做功与路径无关，场力做功都这样，都是只与势有关，电位就是电场的势
    - 电位与电场强度一一对应，一个电位就是一个场强
4. 电压
    - 电位差就是电压
5. 环路定理
    - 电场内绕一圈回到原点，做功为0，则对力进行闭合线积分，结果为0，则面积分为0，说明无漩涡
    - 静电场中：试探电荷绕行一周，电势不变，做功为0
6. 累加法算电位
    - 电位是标量，直接加和

## 1-2
### 导体和电介质
1. 静电场中的导体
    - 导体内电场为0
    - 导体为等势体，内部无电场
    - 导体表明的电场垂直于导体表面
    - 导体带点的话，电荷只分部于表面
2. 静电场中的电介质
    - 分子分为：极性分子，非极性分子
        - 非极性分子在电场作用下会产生电偶极子对（+/-）
        - 极性分子本身会具有电偶极子，无电场 -> 乱序，有电场 -> 沿着电场方向排序
    - 静电场会极化电介质，让电介质的性质趋近于导体
        - 电介质的分子在电场中极化的程度叫作`电极化强度p`
    - 极化电介质产生的电位 = 面电荷产生的电位+体电荷产生的电位
    - 电极化强度P：P= xe0E
        - x：`电极化率`,x是相对于e0的一个系数，e0表示导体的电极化强度，x*e0表示相对于导体，电介质的电极化强度
    - 极化电荷产生的电场和原电场附加产生完整电场
        - 极化电场强度计算：把原本的电场强度公式的电荷密度 -> 极化面电荷密度+极化体电荷密度
### 高斯通量/散度定理
3. 高斯定律
    - 积分形式：E*S = q/e0 （面积积分 = 常数）
        - 适用于电场对称情况下
        - 尽量推导一遍
    - q = q0+q（极化）
    - D = e0*E*S （DS = q）
        - 算上极化电荷
        - D = 真空介电常数+相对介电常数 
    - 算静电场用的

## 1-3
1. 基本方程
    - D*S = q   
        - 微分形式：->  `拉普拉斯算子·D = ρ` -> 说明静电场是有源场
    - E*l = 0   
        - 微分形式：->  `拉普拉斯算子*E = 0` -> 说明能量守恒
    - D = e*E
2. 边界衔接条件
    - D2-D1 = α -> 法向差值
    - E1 = E2   -> 切向相等
    - tan(α1)/tan(α2) = e1/e2
---
## 1-4
1. 唯一性定理
    - 指的是根据某一点的电荷密度，根据泊松方程和拉普拉斯方程，能算出唯一的电位
    - 电荷密度 -> 电位
    - 推导
        - 拉普拉斯算子·D = ρ
        - D = e*E
        - E = - 拉普拉斯算子(电位)
            - ρ/e = - 拉普拉斯算子·(e*拉普拉斯算子(电位)) = - 拉普拉斯算子²(电位)
2. 边值问题
    - 已知边界电位情况
    - 已知边界电位变化情况
    - 1+2
        - 为什么要知道边值，因为知道后可以根据唯一性定理确定区域电位，如果区域无限小，可以确定每一点的电位
        - 用唯一性定理那写的公式能求出来

## 1-7
1. 镜像法
    1. 点电荷对带电无限大导体屏幕
        - 对称位置假设一个`-q`的电荷，然后正常求
    2. 点电荷对两种介质
        - 两种介质e1，e2
        - 假设
            - 一个全为e1介质：原位置q0，对称q1
            - 一个全为e2介质，对称q2
            - 算距离原位置r的电荷受到的场强
                - q1 = (e1-e2/e1+e2)*q0
                - q2 = (2*e2/e1+e2)*q0
    3. 点电荷对接地导体球
        - 导体球半径：R
        - 球电荷间距：d
        - 等效电荷距离秋心距离：b       -> b = R²/d
        - 等效电荷电荷量：q1            -> q1 = Rq/d
2. 电轴法
    - 用于两根圆柱导体情况下的电场，当圆心间距远远大于圆柱半径时，可忽略圆半径
    - 圆心间距：2h
    - 圆柱半径：a
        - 假设：两个圆柱连线上有两根等效细导线
            - 导线间距2b
        1. `a²+b² = h²`
        2. 电位 = `(线密度/2Π)*ln(b-(h-a)/b+(h-a))` 或 `(线密度/2Π)*ln(b+(h-a)/b-(h-a))`
            - b,h-a有关

## 1-8
1. 电容
    - C = Q/U = D*S/E*L = 面积分`eE*S`/线积分`E*L`
        - e已知，S,L是积分的区域，求电容也就是求积分区域的E
    - 求解方法
        - Q。假设Q
            - Q -> D -> E -> U -> C
        - U：假设U
            - U -> 电位 -> E -> D -> Q -> Q 
---
### 1-9
1. 静电能量
    - 计算：外力做功
    - 说明：在线性介质中，电场能量只与状态有关
    - 关系：电场能量 -> 电位 -> 电荷密度，一一相关
    - E = 1/2*q*电位
2. 能量密度
    - 1/2* 电荷密度*电位
        - w = 1/2*E*D
    - 算的时候要注意：源本身具有能量，源外也有能量，要分两个区域都算出来
3. 静电力
    - 虚功计算
        - 外部做功 = 静电能量+静电力做功
            1. 假设：带电体的带电量不变
                - 外部做功 = 0：静电能量 = -静电力做功
            2. 假设：系统电位不变
                - 静电能量 = 0：外部做功 = 静电力做功
