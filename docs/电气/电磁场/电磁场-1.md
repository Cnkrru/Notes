# 第一章：静电场
## 1-1
1. 电场强度
    - F = q*E
    - E = q/4ΠR²
2. 叠加积分 -> 电场强度
    - 点：同1
    - 线：公式
    - 面：类型
    - 体：类型
3. 电位
    - 电势高度
    - 电势 = q/4ΠR
4. 环路定理
    - 静电场中：试探电荷绕行一周，电势不变，做功为0
5. 旋度
    - 长度的积分可以转换为面积的积分
    - 在该转换过程中，可以把面积看作一个个无线小的面点，看作圆，求旋度，就是求圆的数量，旋度高，外层‘原始积分——线积分’内的小圆越多，看起来就是漩涡越多。反之内部圆少，说明内部无旋
    - 算面积分引入拉普拉斯算子来表示
6. 累加法算电位
    - 电位是标量，直接加和

## 1-2
1. 静电场中的导体
    - 导体内电场为0
    - 导体为等势体，内部无电场
    - 导体表明的电场垂直于导体表面
    - 导体带点的话，电荷只分部于表面
2. 静电场中的电介质
    - 静电场会极化电介质，让电介质的性质趋近于导体
    - 极化电介质产生的电位 = 面电荷产生的电位+体电荷产生的电位
    - 电极化强度P：P= xe0E
        - x：x是相对于e0的一个系数，e0表示导体的电极化强度，x*e0表示相对于导体，电介质的电极化强度
3. 高斯定律
    - E*S = q/e0 （面积积分 = 常数）
    - q = q0+q（极化）
    - D = e0*E*S （DS = q）
    - 算静电场用的

## 1-3
1. 基本方程
    - D*S = q   ->  `拉普拉斯算子·D = ρ`
    - E*l = 0   ->  `拉普拉斯算子*E = 0`
    - D = e*E
2. 边界衔接条件
    - D2-D1 = α -> 法向差值
    - E1 = E2   -> 切向相等
    - tan(α1)/tan(α2) = e1/e2
---
## 1-4
1. 唯一性定理
    - 指的是根据某一点的电荷密度能算出唯一的电位
    - 电荷密度 -> 电位
    - 推导
        - 拉普拉斯算子·D = ρ
        - D = e*E
        - E = - 拉普拉斯算子(电位)
            - ρ/e = - 拉普拉斯算子·(e*拉普拉斯算子(电位)) = - 拉普拉斯算子²(电位)
2. 边值问题
    - 已知边界电位情况
    - 已知边界电位变化情况
    - 1+2
        - 为什么要知道边值，因为知道后可以根据唯一性定理确定区域电位，如果区域无限小，可以确定每一点的电位
