# 第一章：变压器概述
1. 变压器结构
    - 一次绕组：变压器接电源侧
        - 一次侧交变频率与电源的交变频率一致
    - 二次绕组：变压器接负载侧
2. 变压器额定值
    - 额定容量Sn
        - Sn = Sn1 = Sn2
    - 额定电压
        - Un1：规定加到一次侧的电压
        - Un2：一次侧加额定电压时，二次侧空载电压
    - 额定电流
        - 单相变压器：Sn = Un1·In1 = Un2·In2
        - 三相变压器：Sn = √3·Un1·In1 = √3·Un2·In2
    - 额定频率
        - 50Hz
