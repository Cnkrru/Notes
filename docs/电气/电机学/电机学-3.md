# 第二章：变压器运行原理
1. 变压器空载运行
    - 一次侧接入额定电压，额定频率的电源上，二次绕组的运行状态
2. 空载运行各电磁量之间的关系
    - 磁通 Φ = Φm·sin(ωt)
    - 一次绕组
        - e = -(N·dΦ/dt) = -ω·N·Φm·sin(ωt-π/2)
            - ω·N·Φm = E1m
            - E1m：一次绕组感应电动势最大值
            - E1 = E1m/√2 = 4.44·f·N1·Φm
    - 二次绕组
        - 二次绕组同理，只是匝数不同
    - 一二次侧电压比
        - k = N1/N2 = E1/E2 = U1/U2
3. 变压器负载运行
    - 折算
        - 折算前后二次侧磁动势不变
        - N1·I2' = N2·I2（折算前后磁动势不变）
            - k = N1/N2
            - 电流折算：I2' = I2/k
            - 电动势折算：E2' = k·E2
            - 电压折算：U2' = k·U2
            - 阻抗折算：Z2' = k²·Z2（电抗、漏抗、阻抗均乘 k²）
    - 等效电路
        - T型等效电路
        - F型等效电路
        - 一型等效电路

5. 空载实验与短路实验
6. 标幺值
    - 标幺值 = 实际值/基准值
        - U/I的基准值一般都会给出，阻抗的基准值需要用给出的U/I的基准值算
        - Zb = Ub/Ib
7. 效率
    - η = P2/P1 = P2/(P2 + pFe + pCu)
        - pFe：铁耗，一般为常数 p0
        - pCu：铜耗，一般由短路损耗算（pCu = β²·pkn）
        - pkn：短路损耗
        - P2：有功功率（= β·Sn·cosφ₂）
    - 最大效率
        - 铁耗与铜耗相等时（可变损耗 = 不变损耗）
        - p0 = β²·pkn
        - βm = √(p0/pkn)
