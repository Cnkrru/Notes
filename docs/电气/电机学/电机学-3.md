# 第二章：变压器运行原理
1. 变压器空载运行
    - 一次侧接入额定电压，额定频率的电源上，二次绕组的运行状态
2. 空载运行各电磁量之间的关系
    - 磁通 = 磁通（max）* sin（wt）
    - 一次绕组
        - E = -（N*磁通变化率）= w*N*磁通（max）*sin（wt-Π/2）
            - w*N*磁通（max）= E1m
            - E1m：一次绕组感应电动势最大值
            - E1 = E1m/根号2 = 4.44f*N1*磁通（max）
    - 二次绕组
        - 二次绕组同理，只是闸数不同
    - 一二次侧电压比
        - k = N1/N2 = E1/E2 = U1/U2
3. 变压器负载运行
    - 折算
        - 折算前后二次侧磁动势不变
        - N2`<二次侧参数>` = N1`<二次侧参数折算值>`（不一定是相乘）
            - k = N1/N2
            - I：原来/折算 = k
            - E：原来/折算 = 1/k
            - U：原来/折算 = 1/k
            - 电抗，漏抗，阻抗折算：原来/折算 = 1/k²
    - 等效电路
        - T型等效电路
        - F型等效电路
        - 一型等效电路
4. 相量图
5. 空载实验与短路实验
6. 标幺值
    - 标幺值 = 实际值/标准值
        - U/I的标准值一般都会给出，阻抗的基准值需要用给出的U/I的基准值算
        - Z = U/I
7. 效率
    - 效率 = 有功功率/输入有功功率 = 有功功率/有功功率+损耗
        - pFe：铁耗，一般为常数p0
        - pCu：铜耗，一般由短路损耗算（pCu = β²pkn）
        - pkn：短路损耗
        - P2：有功功率（βSncos（α2））
    - 最大效率
        - 铁耗与铜耗一致时
        - p0 = β²pkn
        - β = 根号下(p0/pkn)
