## 变压器基础
1. 原理：电磁感应原理
2. 作用：将一个电压电流转换为另一组频率相同，不同电压和电流，传电能
    - 不能改直流电
3. 组成：铁心+绕组+辅助部件
    - 铁心用于磁路
    - 绕组用于电路
    - 铁心材料：硅钢片
        - 材料：减少磁滞损耗
        - 形状：减少涡流损耗
    - 绕组材料：铜导线
        - 通入电流产生磁动势，建立磁通，传递能量
        - F = N*I = 磁通*磁阻
    - 辅助部件
        - 油箱：容纳铁心和绕组
        - 储油罐：平衡油桶高度
        - 绝缘套管：引入绕组接线端
        - 分接开关：改变接线端改变变比
4. 变比
    - K = U1/U2 = E1/E2 = I2/I1
5. 变压器容量和额定电压与额定电流
    - Sn = In*Un = 根号3 *In *Un*(三相)
        - 要区分线相

## 空载运行
1. 空载运行状态
    - 二次侧空载，二次侧电流为0
    - 理论上，一次侧电流也应该为0，但是一次侧有电压，且有阻抗，所以有微小电流
2. 空载电流
    - 一次侧加额定电压
    - 电流 -> 损耗+主磁通
        - 损耗：主要是铁耗，铜耗不算    -> 无功部分
        - 磁通：占大头                 -> 有功部分
    - 占额定电流`10%`以内
3. 波形
    - 磁通为正弦波，空载电流为尖顶波
    - 磁通为平顶波，空载电流为正弦波
4. 磁通与电动势
    - 主磁通：一，二次侧
    - 漏磁通：只链一次侧，主要是空气
    - 电动势：E = 4.44*f*N*磁通
5. 损耗
    - 损耗 = 铜损+铁损
    - 铜损≈0，铁损≈空载损耗
    - 变压器运行发热 -> 有功功率，发热一定有有功功率
6. 等效电路图(一定要会画)

## 负载运行
1. 能量传递
    - P1 -> P(cu1)+P(fe)+P(cu2) -> P2
2. 磁通
    - 磁通 = 一次漏磁通 + 主磁通 + 二次漏磁通
3. 状态
    - F1+F2 = F
        - 一次侧磁动势+二次侧磁动势 = 主磁通
    - I1 = I0+I
        - I1:满载
        - I0:空载
        - I :负载变化
            - I0小时，变比接近理想变压器
            - I0小 -> 变压器阻值大
4. 折算
    - 折算比K
    - T型等效电路（重要）
5. 空载实验与负载实验
    - 空载实验损耗  -> P(fe)
    - 负载实验损耗  -> P(Cu)

## 变压器运行特性
1. 标幺值
    - 实际值/标准值
        - 标准值一般是额定值
2. 外特性
    - 一次侧加额定电压，fN不变
        - 二次侧端电压U2随负载电流I2（负载系数β）变化的情况
    - 电压变化率
        - 电压变化率 = U2额定值 - U2实际值 / U2额定值
        - 电压变化 = U2额定值-U2实际值 = β(Rx*cos(α)+Zx*sin(α))
            - β = I2实际值 / I2额定值
    - β越小越好，漏阻抗越小越好，电压变化率就越小
3. 效率特性
    - 效率 = 输出有功功率P2 / 输入有功功率 P1
        - P1 = P2+P(fe)+P(cu)
            - P(fe):固定值，与β无关
            - P(cu):= β²*P(kn)
            - P2:β*Sn*cos(角度2)
    - 效率最大值：铁耗 = 铜耗
        - β一般在0.5-0.6
        - 计算时，P(fe) < P(kn)

## 变压器连接组标号
1. 两种三相变压器
    - 组式
    - 心式
2. 绕组接法
    - 接法：Y/y(星形)，D/d(三角形)
        - 星形：尾部相连
        - 三角形：首尾相连
            - 高压侧大写，低压侧小写
            - 首端ABC(abc)，末端XYZ(xyz)
        - Yy/Yd/Dy/Dd
            - 同字母：偶数类组号
            - 不同字母：奇数类组号
            - 组号总共12个
            - 连接组号 = ( E(AB) - E(ab) ) / 30°
