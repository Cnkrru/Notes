## 位运算符

| 运算符 | 名称 | 语法 | 说明 | 示例 | 应用场景 |
| :- | :- | :- | :- | :- | :- |
| **&** | 按位与 | `a & b` | 两位都为 1 时结果为 1 | `0b1010 & 0b1100 = 0b1000` | 位掩码、判断奇偶、清除位 |
| **\|** | 按位或 | `a \| b` | 只要一位为 1 结果就为 1 | `0b1010 \| 0b1100 = 0b1110` | 设置特定位 |
| **^** | 按位异或 | `a ^ b` | 两位不同时结果为 1 | `0b1010 ^ 0b1100 = 0b0110` | 交换变量、翻转位、加密 |
| **~** | 按位取反 | `~a` | 0 变 1，1 变 0 | `~0b1010`（取决于位宽） | 生成掩码 |
| **<<** | 左移 | `a << n` | 左移 n 位，右侧补 0 | `0b1010 << 2 = 0b101000` | 乘以 2^n |
| **>>** | 右移 | `a >> n` | 右移 n 位，无符号补 0 | `0b1010 >> 2 = 0b0010` | 除以 2^n |

## C++ 位运算工具

### bitset 库

```cpp
#include <bitset>
bitset<8> b(0b10100101);
cout << b;                         // 10100101
cout << b.count();                 // 4（1 的个数）
cout << b.test(2);                 // true（第 2 位是否为 1）
b.set(1);                          // 将第 1 位置 1
b.reset(3);                        // 将第 3 位置 0
b.flip();                          // 所有位取反
```

### 常用位运算技巧

```cpp
// 检查第 k 位是否为 1
bool bit = (x >> k) & 1;

// 将第 k 位置 1
x |= (1 << k);

// 将第 k 位置 0
x &= ~(1 << k);

// 翻转第 k 位
x ^= (1 << k);

// 判断是否为 2 的幂
bool is_pow2 = (x > 0) && !(x & (x - 1));

// 计算二进制中 1 的个数（C++20 内置）
cout << popcount(0b10100101);       // 4
```
