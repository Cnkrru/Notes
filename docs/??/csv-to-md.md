# CSV 转 Markdown 表格

## 转换规则

### 基本格式

```
| 列1 | 列2 | 列3 |
| --- | --- | --- |
| 值1 | 值2 | 值3 |
```

- 第一行为表头，各列用 `|` 分隔，首尾各一个 `|`
- 第二行为分隔行，`---` 数量与列数一致
- 后续行为数据行

### 对齐方式

| 写法 | 效果 |
| :--- | :--- |
| `:---` | 左对齐 |
| `:---:` | 居中 |
| `---:` | 右对齐 |

### 转义

单元格内容中的 `|` 需转义为 `\|`，否则会被解析为列分隔符。

## 示例

输入 CSV：

```
姓名,年龄,城市
张三,28,北京
李四,35,上海
```

输出 Markdown：

```markdown
| 姓名 | 年龄 | 城市 |
| --- | --- | --- |
| 张三 | 28 | 北京 |
| 李四 | 35 | 上海 |
```

## 处理要点

1. 读取 CSV 时用 `utf-8-sig` 解码，兼容带 BOM 的文件
2. 自动识别分隔符（Tab > 逗号 > 分号）
3. 每行单元格数不足时补齐空字符串
4. 输出用 `utf-8` 编码
5. `|` 字符转义为 `\|`
