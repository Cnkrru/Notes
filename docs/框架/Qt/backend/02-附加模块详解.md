Qt 附加模块针对特定用途，可能在部分平台有限制。以下为最常用的附加模块详解。

## Qt Multimedia — 多媒体处理

基于 FFmpeg 7.1.3 后端，提供跨平台多媒体能力。

### 音频播放

```cpp
QMediaPlayer *player = new QMediaPlayer;
QAudioOutput *audioOutput = new QAudioOutput;
player->setAudioOutput(audioOutput);
player->setSource(QUrl::fromLocalFile("music.mp3"));
player->play();
```

### 视频播放

```qml
// QML 方式
import QtMultimedia

MediaPlayer {
    id: mediaPlayer
    source: "video.mp4"
    audioOutput: AudioOutput {}
    videoOutput: videoOutput
}

VideoOutput {
    id: videoOutput
    anchors.fill: parent
}
```

### 摄像头访问

```cpp
QCamera *camera = new QCamera;
QImageCapture *imageCapture = new QImageCapture;
QMediaCaptureSession *session = new QMediaCaptureSession;
session->setCamera(camera);
session->setImageCapture(imageCapture);
camera->start();
// 拍照
imageCapture->captureToFile("photo.jpg");
```

### 屏幕捕获

```cpp
QScreenCapture *screenCapture = new QScreenCapture;
QMediaCaptureSession *session = new QMediaCaptureSession;
session->setScreenCapture(screenCapture);
screenCapture->start();
```

### 3D 空间音频

Qt Spatial Audio 子模块支持声源定位和房间混响效果。

## Qt SQL — 数据库集成

三层架构：驱动层 → SQL API 层 → UI 层。

### 连接数据库

```cpp
QSqlDatabase db = QSqlDatabase::addDatabase("QSQLITE");
db.setDatabaseName("mydata.db");
if (!db.open()) {
    qDebug() << "Cannot open database";
}
```

### 执行查询

```cpp
QSqlQuery query;
query.exec("CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT)");
query.exec("INSERT INTO users (name) VALUES ('Alice')");

query.exec("SELECT * FROM users");
while (query.next()) {
    QString name = query.value("name").toString();
    qDebug() << name;
}
```

### Model/View 集成

```cpp
QSqlTableModel *model = new QSqlTableModel;
model->setTable("users");
model->select();

QTableView *view = new QTableView;
view->setModel(model);
```

内置支持 SQLite 驱动，同时支持 MySQL、PostgreSQL、ODBC 等。

## Qt Concurrent — 高级并发

无需使用底层互斥锁即可编写多线程程序。

### 异步任务

```cpp
// 在另一线程运行函数
QFuture<int> future = QtConcurrent::run([]() {
    return heavyComputation();
});

// 使用 QFutureWatcher 监控
QFutureWatcher<int> *watcher = new QFutureWatcher<int>;
connect(watcher, &QFutureWatcher<int>::finished, [watcher]() {
    int result = watcher->result();
    qDebug() << "Result:" << result;
});
watcher->setFuture(future);
```

### Map 操作

```cpp
QList<int> list = {1, 2, 3, 4, 5};
QFuture<void> future = QtConcurrent::map(list, [](int &value) {
    value *= 2;
});
```

### Filter 操作

```cpp
QList<int> list = {1, 2, 3, 4, 5, 6};
QFuture<int> future = QtConcurrent::filtered(list, [](int value) {
    return value % 2 == 0;
});
```

### 可配置任务

```cpp
QFuture<int> future = QtConcurrent::task([]() {
    return heavyComputation();
}).onThreadPool(threadPool).start();
```

## Qt WebEngine — 网页引擎

基于 Chromium 项目，支持在应用中嵌入完整 Web 内容。

### QML 方式

```qml
import QtWebEngine

WebEngineView {
    anchors.fill: parent
    url: "https://www.qt.io"
}
```

### Widget 方式

```cpp
QWebEngineView *view = new QWebEngineView;
view->load(QUrl("https://www.qt.io"));
view->show();
```

支持 HTML5、JavaScript、CSS3 等现代 Web 标准。

## Qt SerialPort — 串口通信

```cpp
QSerialPort serial;
serial.setPortName("COM3");
serial.setBaudRate(QSerialPort::Baud9600);
serial.setDataBits(QSerialPort::Data8);
serial.setParity(QSerialPort::NoParity);
serial.setStopBits(QSerialPort::OneStop);

if (serial.open(QIODevice::ReadWrite)) {
    serial.write("Hello");
    connect(&serial, &QSerialPort::readyRead, [&serial]() {
        QByteArray data = serial.readAll();
        qDebug() << data;
    });
}
```
