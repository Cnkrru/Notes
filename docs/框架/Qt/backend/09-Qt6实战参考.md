## 与 Electron 概念对照

把 Qt 概念映射到你熟悉的 Electron 概念，帮助快速建立心理模型。

| Electron / Vue / TS | Qt6 | 说明 |
| --- | --- | --- |
| IPC（ipcMain / ipcRenderer / contextBridge） | signal/slot（信号槽） | `connect(sender, &Sender::signal, receiver, &Receiver::slot)`。跨线程自动排队投递，等价于 IPC 的消息派发，且类型安全 |
| BrowserWindow + 渲染进程 HTML/CSS/JS | QMainWindow + QWidget / QML | `QMainWindow` 约等于主窗口；Qt Widgets 用 C++ 代码或 QSS 控制样式；Qt Quick 用 QML（类似声明式 Vue 模板） |
| BrowserWindow.webContents.send / on | 信号槽 / QMetaObject::invokeMethod | 主线程与工作线程之间通信 |
| ipcMain.handle + contextBridge | Q_INVOKABLE + QML_ELEMENT | 把 C++ 方法/属性暴露给 QML，QML 里可直接调用 |
| electron-builder / 打包资源 | qrc（Qt Resource System，`: 资源路径`） | 资源编译进可执行文件，路径形如 `:/icons/foo.png`，相当于打包 assets |
| main process（Node） | QCoreApplication / 主线程事件循环 | `app.exec()` 运行事件循环 |
| Chromium 网络栈 fetch / axios | QNetworkAccessManager + QNetworkReply | 异步 HTTP 客户端，信号驱动，类似 fetch Promise |
| Node net / ws | QTcpServer / QTcpSocket / QUdpSocket | 底层 TCP/UDP 通信 |
| Express / Koa（本地服务） | QHttpServer（Qt 6.4+） | 进程内起 HTTP 服务 |
| localStorage / electron-store | QSettings | 跨平台持久化配置（注册表 / INI / plist） |
| SQLite（better-sqlite3 / knex） | Qt Sql（QSqlDatabase + QSQLITE 驱动） | 内置 SQLite，另提供 ORM 风格模型 QSqlTableModel |
| Vue 响应式（ref / reactive） | Q_PROPERTY + NOTIFY 信号 | 属性变化时发 NOTIFY 信号驱动 QML 绑定刷新 |
| Worker Thread（Node worker_threads） | QThread / QThreadPool / QRunnable | 多线程与线程池 |
| setInterval / setTimeout | QTimer / QTimer::singleShot | 定时器 |
| <video> / <audio> / HTMLMediaElement | QMediaPlayer + QAudioOutput + QVideoWidget | 音视频播放 |

一点提醒：Widgets 与 Qt Quick(QML) 是两套不同的 UI 技术。Widgets 用 C++ 写界面、适合工具型桌面应用；Quick 用 QML 声明式写界面、适合动画/触控/复杂交互。AL 项目若追求开发效率和 Electron 迁移手感，可优先考虑 Qt Quick；若追求传统桌面外观与成熟控件，用 Widgets。两者都可混用 C++ 业务逻辑。

## Qt Core

Qt Core 是所有 Qt 应用的基石，包含事件循环、对象模型、容器、字符串、文件 I/O、JSON、线程、定时器等。

### QObject 与对象模型

**用途**：所有需要信号槽、属性、父子管理的类的基类。不可拷贝（无拷贝构造/赋值），一律用指针。

关键 API：
- `Q_OBJECT` 宏：声明在类体内，启用信号槽/属性/meta-object，需配合 moc
- `QString objectName()` / `void setObjectName(const QString&)`：对象名，用于 `findChild`、调试
- 静态 `connect(...)`：多种重载（见下节）
- `QObject* parent()` / `setParent()`：父子树，父析构时自动删除子
- `T findChild<T>(name)` / `QList<T> findChildren<T>(name)`：按对象名查子对象
- `QVariant property(name)` / `setProperty(name, value)`：动态属性
- `void deleteLater()`：安全延迟删除（事件循环回到时销毁）
- `bool moveToThread(QThread*)`：把对象迁移到其他线程
- `QString tr(...)`：国际化翻译
- `qobject_cast<T>(obj)`：跨库动态类型转换（不需要 RTTI）
- 信号 `destroyed(QObject*)`、`objectNameChanged(...)`

```cpp
class Worker : public QObject {
    Q_OBJECT
public:
    using QObject::QObject;
    void init() {
        setObjectName("mainWorker");
    }
};

// 用法
Worker *w = new Worker(nullptr);
w->init();
Worker *found = w->findChild<Worker*>();
```

### 信号与槽（signals & slots）

**用途**：Qt 的跨对象通信机制，等价于 Electron 的 IPC 事件派发。类型安全、松耦合。

关键 API：
- 信号：在 `signals:` 段声明，`emit` 发射；**只需声明，不实现**
- 槽：普通成员函数，用 `public slots:` 段或直接作为成员函数
- 新版连接语法（编译期检查）：`connect(sender, &Sender::signal, receiver, &Receiver::slot)`
- 旧版字符串语法（运行期检查）：`connect(sender, SIGNAL(sig(args)), receiver, SLOT(slot(args)))`
- Lambda 连接：`connect(sender, &Sender::signal, this, [=]{ ... })`
- 第五参数连接类型：`Qt::AutoConnection`（默认）、`Qt::QueuedConnection`（跨线程）、`Qt::DirectConnection`
- **必须传 context 对象**（通常是 `this`）：保证 lambda 在正确的线程执行，且对象销毁时自动断开连接

```cpp
class Counter : public QObject {
    Q_OBJECT
public:
    explicit Counter(QObject *parent = nullptr) : QObject(parent), m_value(0) {}
    int value() const { return m_value; }

public slots:
    void setValue(int v) {
        if (v != m_value) {
            m_value = v;
            emit valueChanged(v);
        }
    }

signals:
    void valueChanged(int newValue);

private:
    int m_value;
};

// 连接（指针成员语法）
Counter a, b;
QObject::connect(&a, &Counter::valueChanged, &b, &Counter::setValue);

// Lambda 连接，带 context
QObject::connect(&a, &Counter::valueChanged, &b, [&b](int v) {
    // b 仍存在时才会执行
});

a.setValue(12);  // b.value() == 12
```

### QString

**用途**：Unicode 字符串类（UTF-16 内部存储），等价于 JS 的 string。所有界面文本、路径、JSON 值都用它。

关键 API：
- 构造/转换：`QStringLiteral("...")`（编译期构造，优先使用）、`QString::fromStdString(s)`、`QString::fromUtf8(bytes)`、`s.toStdString()`、`s.toUtf8()`
- 格式化：`QString("%1 %2").arg(a).arg(b)`（`%N` 占位符）
- 数字：`QString::number(int/double)`、`s.toInt(bool* ok)`、`s.toDouble(bool* ok)`
- 查询：`isEmpty()`、`contains()`、`startsWith()`、`endsWith()`、`size()/length()`
- 修改：`append()`、`prepend()`、`replace()`、`trimmed()`、`toUpper()/toLower()`
- 拆分/切片：`split(sep)` 返回 `QStringList`、`sliced(pos, n)`、`first(n)`、`last(n)`（`left/mid/right` 在 Qt6 已弃用）
- 宏：`qPrintable(str)` 取 `const char*`

```cpp
#include <QString>
#include <QStringList>
#include <QDebug>

QString name = QStringLiteral("Alice");
QString msg = QStringLiteral("Hello %1, you have %2 new messages")
                  .arg(name)
                  .arg(42);          // "Hello Alice, you have 42 new messages"

int port = QStringLiteral("8080").toInt();   // 8080
QStringList parts = QStringLiteral("a,b,c").split(',');  // ("a","b","c")
QString cleaned = QStringLiteral("  Hi  ").trimmed();    // "Hi"

QString num = QString::number(255, 16);      // "ff"
QByteArray utf8 = msg.toUtf8();              // 编码为 UTF-8
qDebug() << msg;
```

### QFile / QFileInfo / QDir

**用途**：文件读写与路径操作，等价于 Node 的 fs 模块。QFile 继承 QIODevice，可用 QTextStream 逐行处理文本。

关键 API：
- 打开：`bool open(QIODevice::OpenMode)`，模式：`ReadOnly` / `WriteOnly` / `ReadWrite` / `Append` / `Truncate` / `Text`
- 读写：`readAll()`、`read(buf, max)`、`write(data, max)`、`flush()`、`seek(pos)`、`atEnd()`、`close()`
- 文件操作：`exists()`、`remove()`、`rename(newName)`、`copy(newName)`、`size()`
- QFileInfo：文件元数据；QDir：目录遍历，如 `QDir::setCurrent()` 切换当前目录

```cpp
#include <QFile>
#include <QTextStream>

void writeLines(const QString &path) {
    QFile f(path);
    if (!f.open(QIODevice::WriteOnly | QIODevice::Text))
        return;
    QTextStream out(&f);
    out << "line one\n";
    out << "line two\n";
    f.close();
}

void readLines(const QString &path) {
    QFile f(path);
    if (!f.open(QIODevice::ReadOnly | QIODevice::Text))
        return;
    QTextStream in(&f);
    while (!in.atEnd()) {
        QString line = in.readLine();
        // process line
    }
}

void readBinary(const QString &path) {
    QFile f(path);
    if (!f.open(QIODevice::ReadOnly))
        return;
    QByteArray data = f.readAll();
    f.close();
}
```

### QJson（QJsonDocument / QJsonObject / QJsonArray / QJsonValue）

**用途**：JSON 解析与序列化，等价于 JS 的 `JSON.parse/stringify`。

关键 API：
- `QJsonDocument::fromJson(QByteArray, QJsonParseError*)` 静态解析；`toJson(Indented/Compact)` 序列化
- `doc.isObject()` / `isArray()` / `object()` / `array()` / `isNull()`（解析失败或空文档）
- QJsonObject：`insert(key, QJsonValue)`、`value(key)`、`contains(key)`、`take(key)`、`remove(key)`、`keys()`、`size()`
- QJsonArray：`append(v)`、`at(i)`、`size()`
- QJsonValue：`toString()`、`toInt()`、`toDouble()`、`toBool()`、`toObject()`、`toArray()`；构造可隐式转换自 QString/int/double/bool

```cpp
#include <QJsonDocument>
#include <QJsonObject>
#include <QJsonArray>
#include <QFile>

void parseAndSave(const QByteArray &raw) {
    QJsonParseError err;
    QJsonDocument doc = QJsonDocument::fromJson(raw, &err);
    if (doc.isNull()) {
        qWarning() << "JSON parse error:" << err.errorString();
        return;
    }
    QJsonObject obj = doc.object();
    QString name = obj.value("name").toString();
    int count = obj.value("count").toInt();

    // 构造并保存
    QJsonObject out;
    out.insert("name", QJsonValue(QStringLiteral("AL")));
    out.insert("count", 42);
    QJsonDocument outDoc(out);
    QFile f(QStringLiteral("config.json"));
    if (f.open(QIODevice::WriteOnly)) {
        f.write(outDoc.toJson(QJsonDocument::Indented));
        f.close();
    }
}
```

### QThread / QThreadPool / QRunnable

**用途**：多线程。QThread 是线程控制对象；QThreadPool 是线程池；QRunnable 是池中的任务单元。等价于 worker_threads。

关键 API：
- 静态：`QThread::currentThread()`、`QThread::idealThreadCount()`、`QThread::msleep(ms)`、`QThread::sleep(sec)`
- 实例：`start()`、`quit()`、`wait()`、`requestInterruption()`、`isRunning()`、`isFinished()`、`virtual void run()`
- QThreadPool：`globalInstance()`、`start(QRunnable*)`、`waitForDone()`、`setMaxThreadCount(n)`、`clear()`、`activeThreadCount()`
- QRunnable：纯虚 `run()`、`setAutoDelete(bool)`（默认 true，池执行完自动 delete）

```cpp
// 推荐用法 1：worker + moveToThread（适合事件驱动任务）
class Worker : public QObject {
    Q_OBJECT
public slots:
    void doWork(const QString &param) {
        QString result = param + QStringLiteral(" done");
        emit resultReady(result);
    }
signals:
    void resultReady(const QString &result);
};

// 在 Controller 中：
class Controller : public QObject {
    Q_OBJECT
public:
    Controller() {
        Worker *worker = new Worker;
        worker->moveToThread(&m_thread);
        connect(&m_thread, &QThread::finished, worker, &QObject::deleteLater);
        connect(this, &Controller::operate, worker, &Worker::doWork);
        connect(worker, &Worker::resultReady, this, &Controller::handleResult);
        m_thread.start();
    }
    ~Controller() {
        m_thread.quit();
        m_thread.wait();       // 必须 quit + wait，直接删除运行中的线程会崩溃
    }
signals:
    void operate(const QString &);
private:
    QThread m_thread;
};
```

```cpp
// 推荐用法 2：QRunnable + QThreadPool（适合一次性后台计算）
#include <QRunnable>
#include <QThreadPool>

class SaveTask : public QRunnable {
public:
    explicit SaveTask(const QByteArray &data) : m_data(data) {}
    void run() override {
        QFile f(QStringLiteral("out.bin"));
        f.open(QIODevice::WriteOnly);
        f.write(m_data);
        f.close();
    }
private:
    QByteArray m_data;
};

// 提交任务（autoDelete 默认 true，无需手动 delete）
QThreadPool::globalInstance()->start(new SaveTask(data));
QThreadPool::globalInstance()->waitForDone();
```

### QTimer

**用途**：定时器，等价于 JS 的 setInterval / setTimeout。

关键 API：
- `start(int msec)`、`stop()`、`timeout()` 信号
- 静态 `QTimer::singleShot(int msec, context, lambda/槽)`：一次性延迟执行
- `setInterval()` / `interval()`、`setSingleShot(bool)`、`isActive()`、`remainingTime()`
- `setTimerType(Qt::PreciseTimer / CoarseTimer / VeryCoarseTimer)`

```cpp
#include <QTimer>

// 周期刷新，如 UI 每 5 秒拉一次数据
QTimer *refresh = new QTimer(this);
connect(refresh, &QTimer::timeout, this, &MainWindow::refreshData);
refresh->start(5000);

// 一次性延迟执行（带 context，对象销毁后不再触发）
QTimer::singleShot(2000, this, &MainWindow::showWelcomeMessage);
```

### QSettings

**用途**：跨平台持久化应用配置，等价于 localStorage / electron-store。Windows 走注册表，也可强制 INI 文件。

关键 API：
- 构造：`QSettings(org, app)` 或 `QSettings(fileName, QSettings::IniFormat)`
- `value(key, defaultValue)`、`setValue(key, value)`、`contains(key)`、`remove(key)`、`sync()`
- `beginGroup(key)` / `endGroup()`：分组前缀
- `beginWriteArray(name, size)` / `setArrayIndex(i)` / `beginReadArray(name)` / `endArray()`：数组
- `allKeys()`、`childKeys()`、`status()`（检查 NoError/AccessError/FormatError）
- 说明：INI 中数字读回是 QString，需用 `toInt()` / `toDouble()` 还原

```cpp
#include <QSettings>
#include <QCoreApplication>

QCoreApplication app(argc, argv);
app.setOrganizationName(QStringLiteral("MySoft"));
app.setApplicationName(QStringLiteral("AL"));

// 写
{
    QSettings s;
    s.beginGroup("MainWindow");
    s.setValue("width", 1280);
    s.setValue("fullscreen", false);
    s.endGroup();
    s.sync();
}

// 读
{
    QSettings s;
    s.beginGroup("MainWindow");
    int w = s.value("width", 1024).toInt();
    bool fs = s.value("fullscreen", true).toBool();
    s.endGroup();
}
```

## Qt Gui

非控件的基础图形能力：图像、字体、颜色、绘制、图标。

### QImage

**用途**：CPU 内存中的位图，面向 I/O 与像素处理（读文件、缩放、改像素）。绘制到屏幕前通常转成 QPixmap。

关键 API：
- 构造：`QImage(fileName)`（加载失败为 null）、`QImage(w, h, QImage::Format)`
- `bool load(fileName)`、`bool save(fileName, format, quality)`
- `width()` / `height()` / `size()` / `isNull()` / `format()`
- 像素：`pixelColor(x, y)` / `setPixelColor(x, y, color)`；批量用 `constBits()` / `scanLine()`
- 变换：`scaled(QSize, Qt::KeepAspectRatio, Qt::SmoothTransformation)`、`convertToFormat(Format)`
- Format 枚举：`Format_RGB32`、`Format_RGBA8888`、`Format_ARGB32_Premultiplied`、`Format_Grayscale8`

```cpp
#include <QImage>

QImage img(QStringLiteral("input.png"));
if (img.isNull())
    return;

QImage thumb = img.scaled(QSize(256, 256), Qt::KeepAspectRatio,
                          Qt::SmoothTransformation);
thumb = thumb.convertToFormat(QImage::Format_ARGB32_Premultiplied);
thumb.save(QStringLiteral("thumb.jpg"), "JPG", 90);
```

### QPixmap

**用途**：屏幕优化显示的位图（底层窗口系统管理像素）。QImage 用于处理，QPixmap 用于显示。

关键 API：
- 构造：`QPixmap(fileName)`（文件或资源路径）、`QPixmap(w, h)`
- `bool load(fileName)`、`loadFromData(QByteArray)`、`bool save(...)`
- `QPixmap::fromImage(QImage)` 静态转换、`pixmap.toImage()`
- `width()` / `height()` / `isNull()` / `fill(QColor)`
- `scaled(...)`、`scaledToWidth`、`scaledToHeight`、`copy(QRect)`
- `setDevicePixelRatio(qreal)`：高分屏适配

```cpp
#include <QPixmap>
#include <QImage>

// 处理用 QImage，显示用 QPixmap
QImage image(QStringLiteral(":/images/photo.png"));
QPixmap pixmap = QPixmap::fromImage(
    image.scaled(200, 200, Qt::KeepAspectRatio, Qt::SmoothTransformation));

// 直接从资源加载
QPixmap icon(QStringLiteral(":/icons/app.png"));
```

### QColor

**用途**：颜色值，支持 RGB/HSV/HSL/CMYK，用于绘制与样式。

关键 API：
- 构造：`QColor(r, g, b, a=255)`、`QColor(Qt::GlobalColor)`（如 `Qt::red`）、`QColor(QString name)`


### QPainter

**用途**：在 QPaintDevice（QWidget、QImage、QPixmap）上绘制图形文字。自定义控件在 `paintEvent()` 中使用。

关键 API：
- `QPainter(QPaintDevice*)` 构造即 begin，析构即 end（或 `begin()` / `end()`）
- 绘制：`drawLine`、`drawRect`、`drawEllipse`、`drawText`、`drawImage`、`drawPixmap`、`drawPolygon`、`drawPath`
- 样式：`setPen(QPen)`（描边）、`setBrush(QBrush)`（填充）、`setFont(QFont)`
- `setRenderHint(QPainter::Antialiasing)` 抗锯齿、`SmoothPixmapTransform` 平滑缩放
- `fillRect(QRect, QColor)`

```cpp
#include <QPainter>

class ChartWidget : public QWidget {
protected:
    void paintEvent(QPaintEvent *) override {
        QPainter p(this);
        p.setRenderHint(QPainter::Antialiasing);
        p.setPen(QPen(Qt::blue, 2));
        p.setBrush(QColor::fromString("#FF8800"));
        p.drawEllipse(rect().adjusted(20, 20, -20, -20));
        p.setPen(Qt::black);
        p.drawText(rect(), Qt::AlignCenter, QStringLiteral("Hello"));
    }
};
```

## Qt Widgets

传统桌面控件体系，全用 C++ 构建界面。

### QApplication

**用途**：QWidget 应用的全局对象，管理事件循环与全局设置。必须在任何控件创建之前构造。

关键 API：
- `int exec()`：进入事件循环，返回退出码；`quit()` 退出
- `setApplicationDisplayName()`、`setStyle("Fusion")`、`setStyleSheet(QString)`：全局 QSS 皮肤
- `setAttribute(Qt::AA_... )`：全局属性
- 信号 `aboutToQuit()`
- 全局指针宏 `qApp`
- 类层级：`QApplication`(Widgets) > `QGuiApplication`(无控件 GUI，QML 用) > `QCoreApplication`(纯后台)

```cpp
#include <QApplication>
```

## Qt Network

网络通信：HTTP 客户端、TCP/UDP、本地 HTTP 服务。

### QNetworkAccessManager + QNetworkReply

**用途**：异步 HTTP 客户端，等价于 fetch / axios。全应用共享一个实例即可。

关键 API：
- 请求：`get(QNetworkRequest)`、`post(request, QByteArray)`、`put(...)`、`deleteResource(...)`、`head(...)`、`sendCustomRequest(...)`
- 配置：`setTransferTimeout(ms)`、`setRedirectPolicy(QNetworkRequest::NoLessSafeRedirectPolicy)`、`setCookieJar(...)`
- QNetworkRequest：`QNetworkRequest(QUrl)`、`setHeader(QNetworkRequest::ContentTypeHeader, "application/json")`、`setRawHeader("User-Agent", ...)`
- 信号：`finished(QNetworkReply*)`
- QNetworkReply：`readAll()`、`error()`（`QNetworkReply::NoError` 表示成功）、`errorOccurred`、`attribute(QNetworkRequest::HttpStatusCodeAttribute)`、`downloadProgress`/`uploadProgress`、`abort()`
- **注意**：回复对象用完 `deleteLater()`，勿在 finished 里直接 delete

```cpp
#include <QNetworkAccessManager>
#include <QNetworkRequest>
#include <QNetworkReply>
#include <QJsonDocument>
#include <QJsonObject>

void getJson(QNetworkAccessManager *nam, const QUrl &url) {
    QNetworkRequest req(url);
    req.setHeader(QNetworkRequest::ContentTypeHeader, QStringLiteral("application/json"));
    QNetworkReply *reply = nam->get(req);
    QObject::connect(reply, &QNetworkReply::finished, [reply]() {
        if (reply->error() == QNetworkReply::NoError) {
            QJsonObject obj = QJsonDocument::fromJson(reply->readAll()).object();
            // handle
        } else {
            qWarning() << "HTTP error:" << reply->errorString();
        }
        reply->deleteLater();
    });
}

void postJson(QNetworkAccessManager *nam, const QUrl &url) {
    QNetworkRequest req(url);
    req.setHeader(QNetworkRequest::ContentTypeHeader, QStringLiteral("application/json"));
    QJsonObject payload{{QStringLiteral("name"), QStringLiteral("AL")}};
    QNetworkReply *reply = nam->post(req, QJsonDocument(payload).toJson());
    QObject::connect(reply, &QNetworkReply::finished, [reply]() {
        int status = reply->attribute(QNetworkRequest::HttpStatusCodeAttribute).toInt();
        QByteArray body = reply->readAll();
        reply->deleteLater();
    });
}
```

### QTcpServer / QTcpSocket

**用途**：底层 TCP 服务端/客户端。QHttpServer 内部即构建于此；适合自定义二进制协议、长连接。

关键 API（服务端）：
- `bool listen(QHostAddress::Any, quint16 port)`、`isListening()`、`close()`
- 信号 `newConnection()`；`nextPendingConnection()` 返回 `QTcpSocket*`、`hasPendingConnections()`
- `serverPort()` / `serverAddress()`、`errorString()`

关键 API（客户端）：
- `connectToHost(host, port)`、`waitForConnected(ms)`、`disconnectFromHost()`、`abort()`
- `write(data)`、`flush()`、`readAll()`、`bytesAvailable()`
- 信号：`readyRead`、`connected`、`disconnected`、`errorOccurred`、`stateChanged`
- `peerAddress()` / `peerPort()`

```cpp
// 服务端：回显服务器
QTcpServer server;
QObject::connect(&server, &QTcpServer::newConnection, [&server]() {
    while (server.hasPendingConnections()) {
        QTcpSocket *sock = server.nextPendingConnection();
        QObject::connect(sock, &QTcpSocket::readyRead, [sock]() {
            sock->write(sock->readAll());          // echo
        });
        QObject::connect(sock, &QTcpSocket::disconnected, sock, &QObject::deleteLater);
    }
});
if (!server.listen(QHostAddress::Any, 8080)) {
    qWarning() << server.errorString();
}
```

```cpp
// 客户端
QTcpSocket socket;
socket.connectToHost(QStringLiteral("127.0.0.1"), 8080);
QObject::connect(&socket, &QTcpSocket::readyRead, [&socket]() {
    QByteArray data = socket.readAll();
    // process incoming data
});
QObject::connect(&socket, &QTcpSocket::connected, [&socket]() {
    socket.write(QByteArrayLiteral("hello"));
    socket.flush();
});
```

### QHttpServer（Qt 6.4+）

**用途**：在应用内嵌 HTTP 服务（如本地 API、调试面板），等价于在 Node 里跑 Express。由 Qt HttpServer 模块提供。

关键 API：
- 路由：`route(pathPattern, method, handler)`、`route(pathPattern, handler)`（全部方法）
- 路径参数用 `<arg>` 占位：`"/api/users/<arg>"`，自动按 handler 参数类型转换（int/QString/...）
- Handler 返回 `QHttpServerResponse`（可接收 `QJsonObject`/`QByteArray`/QString 自动包装）
- `QHttpServerRequest`：`url()`、`method()`、`headers()`、`body()`
- 监听：`QAbstractHttpServer::listen(port)` 或 `listen(QHostAddress, port)`；新版需配合 `QTcpServer` + `server.bind(tcpServer)`（见下）
- `setMissingHandler(...)`：自定义 404

```cpp
#include <QHttpServer>
#include <QJsonObject>
#include <QJsonDocument>
#include <QTcpServer>

QHttpServer server;

// GET /api/users/42
server.route(QStringLiteral("/api/users/<arg>"), QHttpServerRequest::Method::Get,
    [](int id, const QHttpServerRequest &req) {
        QJsonObject obj{{QStringLiteral("id"), id},
                        {QStringLiteral("path"), req.url().path()}};
        return QHttpServerResponse(QJsonDocument(obj).toJson(),
                                   QStringLiteral("application/json"));
    });

// POST /api/users（JSON body）
server.route(QStringLiteral("/api/users"), QHttpServerRequest::Method::Post,
    [](const QHttpServerRequest &req) {
        QJsonObject body = QJsonDocument::fromJson(req.body()).object();
        body.insert(QStringLiteral("received"), true);
        return QHttpServerResponse(QJsonDocument(body).toJson(),
                                   QHttpServerResponder::StatusCode::Created);
    });

auto tcpServer = new QTcpServer;
tcpServer->listen(QHostAddress::Any, 8080);
server.bind(tcpServer);
```

### QUdpSocket

**用途**：UDP 数据报收发（局域网发现、音视频传输、状态广播等）。

关键 API：
- `bind(QHostAddress::Any, port)` / `bind(port)`
- 发送：`writeDatagram(QByteArray, QHostAddress, port)`
- 接收：信号 `readyRead`；`pendingDatagramSize()`、`hasPendingDatagrams()`、`readDatagram(buf, size, &addr, &port)`、`receiveDatagram()` 返回 `QNetworkDatagram`
- 组播：`joinMulticastGroup()`、`leaveMulticastGroup()`

```cpp
#include <QUdpSocket>

// 接收端
QUdpSocket *udp = new QUdpSocket(this);
udp->bind(QHostAddress::LocalHost, 7755);
QObject::connect(udp, &QUdpSocket::readyRead, [udp]() {
    while (udp->hasPendingDatagrams()) {
        QNetworkDatagram dg = udp->receiveDatagram();
        QByteArray data = dg.data();
        QHostAddress from = dg.senderAddress();
        quint16 port = dg.senderPort();
        // process
    }
});

// 发送端（无需 bind）
QUdpSocket sender;
sender.writeDatagram(QByteArrayLiteral("ping"), QHostAddress::LocalHost, 7755);
```

## Qt Qml / Quick

声明式 UI（QML 类似 Vue 模板），C++ 提供业务逻辑并暴露给 QML。QML 开发需要 `QGuiApplication`（而非 QApplication）。

### QQmlApplicationEngine

**用途**：加载并运行 QML 应用的引擎入口，等价于 Vue 应用挂载 + 渲染进程启动。

关键 API：
- 构造后 `load("main.qml")`（本地文件或 qrc 路径）或 `load(QUrl)`
- `loadFromModule("com.example.app", "Main")`：从 QML 模块加载（配 CMake `qt_add_qml_module`）
- `setInitialProperties(QVariantMap)`：加载前注入初始属性
- 信号 `objectCreated(QObject*, QUrl)`：组件创建完成（`object==nullptr` 表示失败）
- `rootObjects()`：根对象列表
- 继承自 QQmlEngine：`rootContext()`、`context()->setContextProperty(name, obj)`、`addImportPath()`、`quit()`
- 注意：引擎不会自动创建根窗口，QML 顶层必须用 `Window`（QtQuick）

```cpp
#include <QGuiApplication>
#include <QQmlApplicationEngine>

int main(int argc, char *argv[]) {
    QGuiApplication app(argc, argv);

    QQmlApplicationEngine engine;
    QObject::connect(&engine, &QQmlApplicationEngine::objectCreationFailed,
                     &app, []() { QCoreApplication::exit(-1); },
                     Qt::QueuedConnection);
    engine.load(QStringLiteral("qrc:/qt/qml/AL/Main.qml"));
    // 或 engine.loadFromModule("com.al.app", "Main");
    return app.exec();
}
```

### QML 类型系统与 C++ 暴露

**用途**：把 C++ 类/属性/方法/枚举暴露给 QML，QML 里实例化与调用，等价于 `contextBridge` + IPC handler，但更直接。

关键 API：
- `Q_PROPERTY(type name READ get WRITE set NOTIFY changed)`：属性，QML 可读可绑定。**可写属性必须配 NOTIFY 信号**，否则 QML 绑定警告
- `Q_INVOKABLE`：声明成员方法可被 QML 直接调用（等价于 public slot）
- `Q_ENUM`：枚举暴露给 QML
- 注册宏（放在类体内，Qt6 推荐）：`QML_ELEMENT`（类名即 QML 名）、`QML_NAMED_ELEMENT(CustomName)`、`QML_SINGLETON`（单例）、`QML_UNCREATABLE(reason)`
- 传统注册函数：`qmlRegisterType<T>("com.example", 1, 0, "Type")`、`qmlRegisterSingletonInstance(uri, 1, 0, "Name", instance)`
- 运行时注入对象：`engine.rootContext()->setContextProperty("backend", &backendObj)`
- 头文件需 `#include <QtQml/qqmlregistration.h>`
- CMake：`qt_add_qml_module(target URI com.al.app VERSION 1.0 SOURCES ... QML_FILES Main.qml)`；类型随 SOURCES 自动注册，无需手动 qmlRegisterType

```cpp
// albackend.h
#include <QObject>
#include <QtQml/qqmlregistration.h>

class ALBackend : public QObject {
    Q_OBJECT
    Q_PROPERTY(QString status READ status WRITE setStatus NOTIFY statusChanged)
    QML_ELEMENT
public:
    explicit ALBackend(QObject *parent = nullptr) : QObject(parent) {}

    QString status() const { return m_status; }
    void setStatus(const QString &s) {
        if (s == m_status) return;
        m_status = s;
        emit statusChanged();
    }

    Q_INVOKABLE int add(int a, int b) { return a + b; }

signals:
    void statusChanged();

private:
    QString m_status = QStringLiteral("idle");
};

// albackend.cpp
#include "albackend.h"
// (空实现即可，注册由 qt_add_qml_module 自动生成)
```

```cpp
// main.cpp —— 用 context property 注入实例（不需要注册的简单方式）
#include <QGuiApplication>
#include <QQmlApplicationEngine>
#include "albackend.h"

int main(int argc, char *argv[]) {
    QGuiApplication app(argc, argv);

    engine.rootContext()->setContextProperty(QStringLiteral("backend"), &backend);
    engine.load(QStringLiteral("qrc:/qt/qml/AL/Main.qml"));
    return app.exec();
}
```

## Qt Multimedia

音视频播放。Qt6 架构变化：`QAudioOutput` 是独立对象，必须用 `player->setAudioOutput()` 挂到 QMediaPlayer 上。

### QMediaPlayer + QAudioOutput

**用途**：播放音视频，等价于 `<audio>` / `<video>` 标签。

关键 API（QMediaPlayer）：
- `setSource(QUrl)`（`QUrl::fromLocalFile(path)` 播本地文件）、`play()`、`pause()`、`stop()`
- `position()` / `setPosition(ms)`（先检查 `isSeekable()`）、`duration()`（毫秒）
- `setPlaybackRate(qreal)`（1.0 为标准速度）、`setLoops(QMediaPlayer::Infinite)` 无限循环
- 信号：`positionChanged(qint64)`、`durationChanged(qint64)`、`playbackStateChanged(PlaybackState)`、`mediaStatusChanged(MediaStatus)`、`errorOccurred(Error, QString)`
- 视频输出：`setVideoOutput(QVideoWidget*)` 或 `setVideoOutput(QGraphicsVideoItem*)`
- `setAudioOutput(QAudioOutput*)`：挂载音频输出（**不设置则无声音**）

关键 API（QAudioOutput）：
- `setVolume(0.0~1.0)`（线性，0 静音）、`setMuted(bool)`、`setDevice(QAudioDevice)`
- 信号：`volumeChanged`、`mutedChanged`、`deviceChanged`

```cpp
#include <QMediaPlayer>
#include <QAudioOutput>

// 播放音频
QMediaPlayer *player = new QMediaPlayer(this);
QAudioOutput *audio = new QAudioOutput(this);
player->setAudioOutput(audio);

QObject::connect(player, &QMediaPlayer::positionChanged, this, [](qint64 pos) {
    // update slider
});
QObject::connect(player, &QMediaPlayer::errorOccurred, this,
    [](QMediaPlayer::Error, const QString &msg) {
        qWarning() << "media error:" << msg;
    });

audio->setVolume(0.6);
player->setSource(QUrl::fromLocalFile(QStringLiteral("C:/music/song.mp3")));
player->play();
```

### QVideoWidget / QGraphicsVideoItem

**用途**：视频显示控件。QVideoWidget 是普通 QWidget，可进布局；QGraphicsVideoItem 用于 QGraphicsScene/View 场景。

关键 API（QVideoWidget，继承 QWidget）：
- 与播放器连接：`player->setVideoOutput(videoWidget)`
- `setFullScreen(bool)`、`setAspectRatioMode(Qt::KeepAspectRatio)`
- `videoSink()`：底层取帧
- 注意：一个媒体对象同一时间只能挂一个显示输出

关键 API（QGraphicsVideoItem）：
- `setSize(QSizeF)`、`setAspectRatioMode(...)`、`nativeSize()`（视频原始尺寸）
- 加入场景：`scene.addItem(item)`；播放器连接：`player->setVideoOutput(item)`

```cpp
#include <QMainWindow>
#include <QVideoWidget>
#include <QMediaPlayer>
#include <QAudioOutput>
#include <QVBoxLayout>

class MediaWindow : public QMainWindow {
public:
    MediaWindow() {
        auto *central = new QWidget(this);
        auto *layout = new QVBoxLayout(central);

        m_video = new QVideoWidget;
        m_video->setAspectRatioMode(Qt::KeepAspectRatio);
        layout->addWidget(m_video);
        setCentralWidget(central);

        m_player = new QMediaPlayer(this);
        auto *audio = new QAudioOutput(this);
        m_player->setAudioOutput(audio);
        m_player->setVideoOutput(m_video);

        m_player->setSource(QUrl::fromLocalFile(QStringLiteral("C:/videos/movie.mp4")));
        m_player->play();
    }

private:
    QMediaPlayer *m_player = nullptr;
    QVideoWidget *m_video = nullptr;
};
```

```cpp
// QGraphicsVideoItem 场景用法
#include <QGraphicsScene>
#include <QGraphicsView>
#include <QGraphicsVideoItem>
#include <QMediaPlayer>

auto *player = new QMediaPlayer;
auto *item = new QGraphicsVideoItem;
player->setVideoOutput(item);

QGraphicsScene scene;
scene.addItem(item);
item->setSize(QSizeF(640, 360));

QGraphicsView view(&scene);
view.show();

player->setSource(QUrl::fromLocalFile(QStringLiteral("C:/videos/movie.mp4")));
player->play();
```

## 常见坑（从 Electron 迁移者的重点提醒）

1. **QObject 不可拷贝**：容器里存指针（`QList<QObject*>`），别存值。
2. **对象所有权靠父子树**：`new QWidget(this)` 由父析构自动释放；`new` 出来的对象要挂 parent 或确保 `deleteLater()`。
3. **信号槽 lambda 必须传 context**：`connect(sender, &S::sig, this, [...]{})`，否则对象销毁后回调仍可能触发。
4. **跨线程信号槽**：默认 `Qt::AutoConnection`，跨线程自动排队；若自定义类型要 `qRegisterMetaType<T>()` 注册后才能跨线程传参。
5. **不要在 UI 线程做耗时 I/O / 计算**：用 `QThreadPool` 或 `moveToThread`；UI 只能在主线程更新。
6. **`QString` 与 `const char*`**：Qt6 中 `const char*` 按 UTF-8 解释；路径统一用 `/`。
7. **资源用 qrc**：资源路径 `:/...`，编译进二进制；图片先转 `QPixmap` 再显示，处理用 `QImage`。
8. **QMediaPlayer 必须挂 QAudioOutput**，否则无声；`setSource` 前可先 `setAudioOutput`。
9. **SQLite 的 `QSqlDatabase` 连接**：不要长期保存副本；结束时 `removeDatabase`。
10. **QML 属性绑定**：C++ 属性必须带 NOTIFY 信号，QML 绑定才自动更新。
