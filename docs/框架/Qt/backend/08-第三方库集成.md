## FFmpeg — 媒体处理

AL 项目用 FFmpeg 替代 Electron 的 ffmpeg 子进程 spawn，实现零拷贝媒体管道。

### 核心库

| 库 | 用途 |
|-----|------|
| `libavformat` | 封装容器（demuxer/muxer），打开/写入媒体文件 |
| `libavcodec` | 编解码器，解码视频帧/音频帧 |
| `libswscale` | 像素格式转换（YUV → RGB，用于缩略图） |

### 数据流

```
AVFormatContext (容器) ──▶ AVPacket (压缩数据)
    │                          │
    │                    avcodec_send_packet
    │                          │
    │                    avcodec_receive_frame
    │                          │
    │                          ▼
    │                     AVFrame (解码像素)
    │                          │
    │                     sws_scale (YUV → RGB)
    │                          │
    │                          ▼
    └──────────────▶ 缩略图 / 帧数据
```

### 解码 + 缩略图核心流程

```cpp
extern "C" {
#include <libavformat/avformat.h>
#include <libavcodec/avcodec.h>
#include <libswscale/swscale.h>
}

// 1. 打开文件
AVFormatContext *fmtCtx = nullptr;
avformat_open_input(&fmtCtx, file, nullptr, nullptr);
avformat_find_stream_info(fmtCtx, nullptr);

// 2. 找视频流 + 解码器
const AVCodec *decoder = nullptr;
int vs = av_find_best_stream(fmtCtx, AVMEDIA_TYPE_VIDEO,
                              -1, -1, &decoder, 0);

// 3. 创建解码上下文
AVCodecContext *codecCtx = avcodec_alloc_context3(decoder);
avcodec_parameters_to_context(codecCtx,
    fmtCtx->streams[vs]->codecpar);
avcodec_open2(codecCtx, decoder, nullptr);

// 4. 解码循环
AVPacket *pkt = av_packet_alloc();
AVFrame *frame = av_frame_alloc();
while (av_read_frame(fmtCtx, pkt) >= 0) {
    if (pkt->stream_index == vs) {
        avcodec_send_packet(codecCtx, pkt);
        while (avcodec_receive_frame(codecCtx, frame) == 0) {
            // frame 是一帧解码后的 YUV 数据
        }
    }
    av_packet_unref(pkt);
}

// 5. 清理
av_frame_free(&frame);
av_packet_free(&pkt);
avcodec_free_context(&codecCtx);
avformat_close_input(&fmtCtx);
```

### 转封装（剪切/合并/格式转换）

转封装只改容器不改编码，速度快。核心：逐包拷贝 + 时间戳重映射。

```cpp
// 输入包的时间戳按输出 timebase 重映射
pkt->pts = av_rescale_q_rnd(pkt->pts,
    inCtx->streams[pkt->stream_index]->time_base,
    outCtx->streams[pkt->stream_index]->time_base,
    AV_ROUND_NEAR_INF | AV_ROUND_PASS_MINMAX);
av_interleaved_write_frame(outCtx, pkt);
```

## SQLite C API — 数据库

AL 项目推荐直接用 SQLite C API 而非 Qt SQL 封装，以获得更好的性能和控制。

### 核心流程

```cpp
#include <sqlite3.h>

// 打开
sqlite3 *db = nullptr;
sqlite3_open_v2("al.db", &db,
    SQLITE_OPEN_READWRITE | SQLITE_OPEN_CREATE | SQLITE_OPEN_FULLMUTEX,
    nullptr);
sqlite3_busy_timeout(db, 5000);

// 预处理
sqlite3_stmt *stmt = nullptr;
sqlite3_prepare_v2(db, "SELECT id, name FROM users WHERE age >= ?",
                   -1, &stmt, nullptr);
sqlite3_bind_int(stmt, 1, 18);

// 遍历
while (sqlite3_step(stmt) == SQLITE_ROW) {
    int id = sqlite3_column_int64(stmt, 0);
    const char *name = (const char*)sqlite3_column_text(stmt, 1);
    // 注意：name 指针在下一次 step 前有效，需立即拷贝
}

sqlite3_finalize(stmt);
sqlite3_close_v2(db);
```

### WAL + 事务

```cpp
// 启用 WAL（读写并发）
sqlite3_exec(db, "PRAGMA journal_mode=WAL;", nullptr, nullptr, nullptr);

// 批量写入必须用事务
sqlite3_exec(db, "BEGIN IMMEDIATE;", nullptr, nullptr, nullptr);
// ... 多条 INSERT
sqlite3_exec(db, "COMMIT;", nullptr, nullptr, nullptr);
```

### 性能收益

与 better-sqlite3 (N-API) 对比：
- 消除 N-API 类型转换开销（~0.1-0.5ms/次）
- Prepared Statement 缓存命中率更高
- 批量事务无异步 Promise 包装

## OpenSSL — 加密

AL 项目用 AES-256-GCM 加密密码管理器数据，scrypt 派生密钥。

### 加密流程

```
password + salt ──scrypt──▶ 32字节 key ──AES-256-GCM──▶ 密文 + 16字节 tag
```

### AES-256-GCM 加密

```cpp
#include <openssl/evp.h>
#include <openssl/rand.h>

EVP_CIPHER_CTX *ctx = EVP_CIPHER_CTX_new();

// 初始化
EVP_EncryptInit_ex2(ctx, EVP_aes_256_gcm(), nullptr, nullptr, nullptr);
EVP_CIPHER_CTX_ctrl(ctx, EVP_CTRL_AEAD_SET_IVLEN, 12, nullptr);
EVP_EncryptInit_ex2(ctx, nullptr, key.data(), iv.data(), nullptr);

// 加密
int len = 0;
EVP_EncryptUpdate(ctx, cipher.data(), &len, plain.data(), plain.size());

// Final + 取 tag
EVP_EncryptFinal_ex(ctx, cipher.data() + len, &tmplen);
EVP_CIPHER_CTX_ctrl(ctx, EVP_CTRL_AEAD_GET_TAG, 16, tag.data());

EVP_CIPHER_CTX_free(ctx);
```

### scrypt 密钥派生

```cpp
std::vector<unsigned char> key(32);
EVP_PBE_scrypt(password.c_str(), password.size(),
               salt.data(), salt.size(),
               32768, 8, 1, 0,  // N=2^15, r=8, p=1
               key.data(), key.size());
```

### 安全要点

- **密钥不持久化**：每次启动从机器指纹重新派生
- **salt 随机且唯一**：每次加密生成新 salt（16 字节）
- **IV 随机**：每次加密生成新 IV（12 字节）
- **兼容旧格式**：AES-256-CBC 向后读取（不再写入新数据）

## 其他库

### md4c — Markdown 解析

替代 markdown-it (JS)，MIT 许可，纯 C 实现：
- 支持 CommonMark + GFM（表格/任务列表/删除线）
- 输出 HTML，QML 可直接渲染
- 速度极快，无外部依赖

### stb_image — 图片解码

替代 Electron nativeImage，header-only 库：
- 支持 JPEG、PNG、BMP、GIF、PSD 等格式
- 用于缩略图生成中的图片解码
- 配合 Qt Image 缩放

### spdlog — 日志

header-only 日志库，替代 Node.js console：
- 支持多 sink（文件/控制台/滚动日志）
- 格式化输出，支持彩色终端
- 线程安全

### nlohmann/json — JSON

header-only C++ JSON 库，替代 Qt 内置 QJsonDocument：
- 语法更简洁 `j["name"] = "AL"`
- 支持 STL 容器互操作
- 广泛使用，生态成熟
