AL 项目后端服务遵循"先用 Qt 官方模块，后续遇瓶颈再升级底层方案"的原则。三大服务：HTTP Server（文件互传/移动端联动）、文件监听（媒体库自动更新）、快捷键（全局操作）。

> 技术栈：Qt 6.11 (MinGW) · C++20 · vcpkg (`x64-mingw-dynamic`)

## HTTP Server — 文件互传

### 方案选择

采用 **QHttpServer**（Qt 6.4+ 正式模块，vcpkg 端口 `qt-httpserver`）。若暂不追加依赖，可用 `QTcpServer` 手写轻量 HTTP（依赖已在 `qtbase` 的 QtNetwork 中）。[$TRAE_REF](https://doc.qt.io/qt-6/qhttpserver.html)

### 设计要点

- **监听地址**：`0.0.0.0:7528`（移动端服务）；流媒体相关仅 `127.0.0.1`
- **路由设计**：
  - `GET /files` — 文件列表
  - `POST /upload` — 文件上传
  - `GET /download/{id}` — 文件下载
  - `POST /convert` — 格式转换（转 FFmpeg 直调）
- **安全**：Token 认证 + 设备白名单（DeviceAuth 审批机制）
- **生命周期**归 `src/modules/file_transfer/` 管理

### 核心实现

```cpp
#include <QHttpServer>
#include <QHttpServerRequest>
#include <QHttpServerResponse>

class HttpServer : public QObject {
    Q_OBJECT
public:
    bool start(quint16 port) {
        m_server.route("/files", QHttpServerRequest::Method::Get,
            [this](const QHttpServerRequest &req) {
                // Token 验证
                if (!m_auth.verify(req))
                    return QHttpServerResponse(QHttpServerResponse::StatusCode::Unauthorized);
                return QHttpServerResponse(m_filesStore.list());
            });

        m_server.route("/download/<arg>", QHttpServerRequest::Method::Get,
            [this](qint64 id, const QHttpServerRequest &req) {
                if (!m_auth.verify(req))
                    return QHttpServerResponse(QHttpServerResponse::StatusCode::Unauthorized);
                auto data = m_filesStore.get(id);
                if (data.isEmpty())
                    return QHttpServerResponse(QHttpServerResponse::StatusCode::NotFound);
                return QHttpServerResponse(data, "application/octet-stream");
            });

        m_server.route("/upload", QHttpServerRequest::Method::Post,
            [this](const QHttpServerRequest &req) {
                if (!m_auth.verify(req))
                    return QHttpServerResponse(QHttpServerResponse::StatusCode::Unauthorized);
                auto id = m_filesStore.save(req.body());
                return QHttpServerResponse(QJsonObject{{"id", id}});
            });

        return m_server.listen(QHostAddress::Any, port) != -1;
    }

    void stop() { /* 关闭监听 */ }

private:
    QHttpServer m_server;
    AuthManager m_auth;          // Token 认证
    DeviceAuth m_deviceAuth;     // 设备白名单
    FilesStore m_filesStore;     // 文件存储
    ConvertManager m_convert;    // 格式转换
};
```

### 注意事项

- `QHttpServer` 需安装 vcpkg 包：`vcpkg install qt-httpserver:x64-mingw-dynamic`
- 上传大文件时考虑流式处理，避免一次性载入内存
- 跨平台后保持路由与响应格式一致，便于移动端对接
- 生产环境建议使用 `QTcpServer` + SSL 或前置反向代理

## 文件监听 — 媒体库自动更新

### 方案选择

采用 **QFileSystemWatcher**。启动时监听仓库根目录，收到变更信号后触发增量扫描。[$TRAE_REF](https://doc.qt.io/qt-6/qfilesystemwatcher.html)

### 设计要点

- 启动时把仓库根目录加入 `addPath()`
- 收到 `directoryChanged` → 增量扫描该目录
- 收到 `fileChanged` → 单文件更新（新增/删除/改名）
- 与 Scanner 配合：监听事件只是"触发信号"，实际差异对比由扫描器基于数据库快照完成

### 核心实现

```cpp
#include <QFileSystemWatcher>
#include <QTimer>

class FileWatcher : public QObject {
    Q_OBJECT
public:
    explicit FileWatcher(Scanner* scanner, QObject* parent = nullptr)
        : QObject(parent), m_scanner(scanner) {
        // 目录变更 → 触发增量扫描
        connect(&m_watcher, &QFileSystemWatcher::directoryChanged,
                this, &FileWatcher::onDirectoryChanged);
        // 文件变更 → 触发单文件更新
        connect(&m_watcher, &QFileSystemWatcher::fileChanged,
                this, &FileWatcher::onFileChanged);

        // 防抖：批量变更合并到一次扫描
        m_debounceTimer.setInterval(500);
        m_debounceTimer.setSingleShot(true);
        connect(&m_debounceTimer, &QTimer::timeout,
                this, &FileWatcher::doScan);
    }

    void watchDirectory(const QString& path) {
        m_watcher.addPath(path);
        // QFileSystemWatcher 非递归，需手动递归添加子目录
        QDirIterator it(path, QDir::Dirs | QDir::NoDotAndDotDot,
                        QDirIterator::Subdirectories);
        while (it.hasNext()) {
            m_watcher.addPath(it.next());
        }
    }

private slots:
    void onDirectoryChanged(const QString& path) {
        m_debounceTimer.start();  // 防抖
    }

    void onFileChanged(const QString& path) {
        if (!QFile::exists(path)) {
            // 文件被删除（编辑器临时删除保存也会触发）
            m_watcher.addPath(path);  // 重新添加监控
            return;
        }
        m_scanner->updateFile(path);
    }

    void doScan() {
        m_scanner->scanIncremental();
    }

private:
    QFileSystemWatcher m_watcher;
    QTimer m_debounceTimer;
    Scanner* m_scanner;
};
```

### 注意事项

- **非递归**：只监听指定目录本身，子目录需逐个 `addPath`（或监听根目录后全量重扫）
- 文件被替换（先删后建）时 `fileChanged` 可能丢失，需配合 `directoryChanged` 兜底
- 监听的路径若被移动/删除，Qt 不会自动恢复，需重新 `addPath`
- **fd 限制**：某些系统默认限制 256 个文件描述符，大量文件监控可能触及此限制
- 极端高频场景（性能不够）再升级 `ReadDirectoryChangesW` (Windows API)

## 快捷键 — 全局操作

### 方案选择

采用 **QShortcut**（应用内）和 QML **Shortcut**（声明式）。窗口内快捷键用 C++ `QShortcut` 或 QML `Shortcut` 类型。[$TRAE_REF](https://doc.qt.io/qt-6/qshortcut.html)

### 设计要点

- 窗口内快捷键：`QShortcut`（C++）或 QML `Shortcut` 类型
- 主要快捷键规划：
  - `Space` — 播放/暂停
  - `Ctrl+Left/Right` — 上一曲/下一曲
  - `Ctrl+M` — 切换迷你播放器
  - `Ctrl+,` — 打开设置
  - `Ctrl+F` — 全局搜索
  - 复制/粘贴等通用操作由系统默认处理

### 核心实现

**QML 声明式快捷键**（推荐用于 UI 层）：

```qml
// 播放器快捷键
Item {
    Shortcut {
        sequence: "Space"
        onActivated: player.togglePlayPause()
    }
    Shortcut {
        sequence: "Ctrl+Left"
        onActivated: player.previous()
    }
    Shortcut {
        sequence: "Ctrl+Right"
        onActivated: player.next()
    }
}

// 全局搜索
Shortcut {
    sequence: "Ctrl+F"
    context: Qt.ApplicationShortcut  // 应用级快捷键
    onActivated: searchBar.forceActiveFocus()
}
```

**C++ 命令式快捷键**（用于核心引擎层）：

```cpp
#include <QShortcut>

// 设置快捷键（Ctrl+,）
auto* settingsShortcut = new QShortcut(QKeySequence("Ctrl+,"), mainWindow);
connect(settingsShortcut, &QShortcut::activated, this, [this]() {
    openSettings();
});

// 迷你播放器切换（Ctrl+M）
auto* miniPlayerShortcut = new QShortcut(QKeySequence("Ctrl+M"), mainWindow);
connect(miniPlayerShortcut, &QShortcut::activated, this, [this]() {
    toggleMiniPlayer();
});
```

### 注意事项

- `QShortcut` **仅应用内生效**（窗口聚焦时），不是系统级全局快捷键
- 若后续需要"程序在后台/未聚焦时也能响应按键"，需升级：
  - 第三方库 `QHotkey`
  - Windows API `RegisterHotKey`
- 快捷键冲突处理：`Qt::ApplicationShortcut` 上下文避免与其他窗口冲突
- 建议在设置页面允许用户自定义快捷键

## 服务生命周期管理

所有后端服务统一由 `ServiceManager` 管理启停：

```cpp
class ServiceManager : public QObject {
    Q_OBJECT
public:
    void startAll() {
        m_httpServer.start(7528);
        m_fileWatcher.watchDirectory(m_paths.vaultDir());
        // 快捷键在 QML 中声明，无需显式启动
    }

    void stopAll() {
        m_httpServer.stop();
        // fileWatcher 随 parent 自动销毁
    }

private:
    HttpServer m_httpServer;
    FileWatcher m_fileWatcher;
    Paths m_paths;
};
```
