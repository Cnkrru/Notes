Qt 6 基础模块在所有支持的平台上可用，并保证源码和二进制兼容。

## Qt Core — 核心非图形类

提供 Qt 框架最基础的功能，是其他所有模块的依赖。

### 信号与槽

Qt 的核心通信机制，类型安全，支持跨线程连接：

```cpp
class Sender : public QObject {
    Q_OBJECT
signals:
    void valueChanged(int newValue);
};

class Receiver : public QObject {
    Q_OBJECT
public slots:
    void onValueChanged(int val) {
        qDebug() << "Value:" << val;
    }
};

// 连接
connect(sender, &Sender::valueChanged, receiver, &Receiver::onValueChanged);
```

### 元对象系统

提供运行时类型信息（RTTI）、动态属性系统和对象树管理：

- `QObject` 是所有 Qt 对象的基类
- 对象树机制自动管理子对象生命周期
- `QPointer` 守卫指针防止悬空指针
- 动态属性：`setProperty()` / `property()`

### 事件系统

事件循环驱动机制，支持事件过滤器和跨线程事件投递：

```cpp
bool MyWidget::eventFilter(QObject *obj, QEvent *event) {
    if (event->type() == QEvent::KeyPress) {
        // 处理键盘事件
        return true;
    }
    return QObject::eventFilter(obj, event);
}
```

### 容器类

所有容器支持隐式共享（COW）：

| 容器 | 说明 |
|------|------|
| `QList` / `QVector` | 动态数组 |
| `QMap` / `QHash` | 键值对容器 |
| `QSet` | 集合 |
| `QString` | Unicode 字符串 |
| `QByteArray` | 字节数组 |
| `QVariant` | 联合类型 |

### 线程支持

```cpp
class WorkerThread : public QThread {
    void run() override {
        // 线程执行逻辑
    }
};

// 或使用 QObject + moveToThread 模式
QThread *thread = new QThread;
Worker *worker = new Worker;
worker->moveToThread(thread);
connect(thread, &QThread::started, worker, &Worker::doWork);
thread->start();
```

### 其他核心功能

- **JSON 与 CBOR**：`QJsonDocument`、`QCborValue`
- **动画框架**：`QPropertyAnimation` 声明式属性动画
- **资源系统**：将文件编译嵌入可执行程序
- **插件系统**：跨边界的动态类型转换
- **进程间通信**：`QLocalSocket`、`QSharedMemory`

## Qt GUI — 图形用户界面基础

### 窗口系统集成

- `QWindow`：跨平台窗口抽象
- `QScreen`：屏幕信息管理
- 事件处理：鼠标、键盘、触摸、手势

### 2D 图形

- `QPainter`：2D 绘制引擎
- `QImage` / `QPixmap`：图像处理
- `QPainterPath`：矢量路径

### RHI 加速图形

Qt Rendering Hardware Interface 统一抽象层，支持多后端：

| 后端 | 平台 |
|------|------|
| Metal | macOS |
| Direct3D 11/12 | Windows |
| Vulkan | 跨平台 |
| OpenGL / OpenGL ES | 跨平台 |

### 矩阵与向量数学

```cpp
QMatrix4x4 matrix;
matrix.translate(1, 2, 3);
matrix.rotate(45, 0, 1, 0);

QVector3D position(1, 0, 0);
QVector3D transformed = matrix * position;
```

### 字体与文本

基于 FreeType 和 HarfBuzz 的高级文本渲染，支持复杂文字排版（如阿拉伯语、印地语）。

## Qt Network — 网络编程

### HTTP 客户端

```cpp
QNetworkAccessManager *manager = new QNetworkAccessManager;
QNetworkRequest request(QUrl("https://api.example.com/data"));
QNetworkReply *reply = manager->get(request);
connect(reply, &QNetworkReply::finished, [reply]() {
    if (reply->error() == QNetworkReply::NoError) {
        QByteArray data = reply->readAll();
        // 处理数据
    }
    reply->deleteLater();
});
```

### TCP/IP Socket

| 类 | 功能 |
|-----|------|
| `QTcpSocket` | TCP 客户端 |
| `QTcpServer` | TCP 服务器 |
| `QUdpSocket` | UDP 通信 |

基于 OpenSSL 的加密传输，通过 `QSslConfiguration` 配置证书和加密参数。
