# command-kit

指令集 SKILL，提供常用开发指令的快速参考与执行指南。

## 功能特性

- 极简操作: 通过简洁指令快速执行文件/文件夹操作
- 增删改查: 支持创建、删除、移动、重命名、编号等常用操作
- SKILL 调用: 支持通过 `use-` 指令调用其他 SKILL
- 即学即用: 格式统一，上手即用

## 指令分类

| 分类 | 说明 |
|------|------|
| 增（Create） | 创建文件和文件夹 |
| 删（Delete） | 删除文件和文件夹 |
| 改（Update） | 移动、重命名、整理编号 |
| 查（Read） | 待扩展 |
| 系统（System） | 调用其他 SKILL |
